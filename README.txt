STAYSCENE 公開用パッケージ
============================

構成
----
index.html               ページ本体
assets/css/style.css     共通・各ジャンル・モバイル用CSS
assets/js/app.js         検索、詳細、比較、ページ切替、ホテルデータ

確認方法
--------
index.htmlをブラウザで開いてください。
公開時は、このフォルダ内の構成を保ったままサーバーへアップロードします。

今回の主な改善
--------------
・スマートフォン本文の不自然な単語途中改行を抑制
・トップのCTAを「1段目1個＋2段目2個」に整理
・専門ページから検索フォームへ移動するショートカットを追加
・モバイル固定ヘッダーを小型化
・検索後はホテル一覧ではなく結果見出しへ移動
・320px幅では4項目ナビを均等配置
・eスポーツのモバイルビジュアルを小型化
・ボタンとフッターリンクのタップ領域を拡大
・小さい確認ラベルと補足文字を読みやすく調整
・注意状態の色コントラストを改善
・アート見出しを320pxでも2行に収まりやすい表現へ調整

注意
----
ホテル名、アクセス、設備、予約リンクなどの掲載情報は、公開前に必ず公式情報で最終確認してください。
